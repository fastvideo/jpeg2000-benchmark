Foreign watermark on the frame and what PSNR is computed against

  codec  frame watermark      applied    PSNR reference
  --------------------------------------------------------------
  fv     2k         none            -     original
  fv     4k         none            -     original
  nv     2k         none            -     original
  nv     4k         none            -     original

  The demo build puts the watermark on the frame BEFORE encoding. In
  that case the decoded frame must not be compared with the source
  file: it would measure the watermark, not the codec. So the
  reference is the frame that came back through a LOSSLESS round trip
  on the same build: it is bit for bit equal to what the encoder
  received. The condition - the watermark must be applied the same way
  every time; this is checked by two independent lossless round trips,
  they must match byte for byte.
